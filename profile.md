# About John Warnicke

John Warnicke is a Solutions Architect and Senior Network Engineer with 15+ years across software development, automation, and enterprise/service-provider networking, on-prem and in the cloud.

## Financial exchange connectivity — Lumen Technologies / CenturyLink (2015–2020)

Five years on the financial desk, rising from IT Operations Tech II to Senior Network Engineer. He supported and ran the global exchange network carrying Thomson Reuters/Refinitiv/LSEG market data: direct CME feeds, managed FINRA connections for large clients, low-latency trading connectivity and managed hosting. As Senior Network Engineer he was the highest level of technical escalation and turned up new financial exchange services.

## Python automation platform — Lumen (2020–2024)

As Lead Solutions Architect, he designed and built the team's large-scale Python bot platform: template-driven auto-deploy, prebuilt OAuth2 integrations to Microsoft Graph and ServiceNow, ticketing functions, and skill bots that logged into network devices to run status checks and changes. Monitoring scripts logged in and opened tickets automatically in response to network events. Full DevOps ownership alongside it: GitHub Actions, Jenkins pipelines (including a migration from Groovy shared libraries to shell scripts), Helm charts, Bicep, dev containers — deploying to vanilla Kubernetes and Rancher, administering all K8s namespaces.

## Service-provider networking

Arista and Ansible automation, Itential orchestration; Cisco Nexus switches as managed customer-edge devices (failover pairs), running L3 routing and multicast routing in VRFs; Juniper QFX 5200s as backbone PEs; Nokia 7750s for L3VPN customer VPRNs; DWDM/optical transport; exchange handoffs with IGMP joins and rendezvous points. Deep protocol work: BGP, MPLS, RSVP-TE, IS-IS, OSPF, IP multicast.

## Voice/video over IP — UNC Chapel Hill (1999–2002)

Ran a converged H.323 voice/video environment; worked on ViDeNet and VCONS FalconIP. Spoke at Internet2 (Washington, DC, 2001) and NorduNet 2000 (Helsinki) on video-over-IP.
